# Echoes of the Sundered Archive

A gacha JRPG for **RPG Maker MV**. You are the last apprentice of a library that remembers every hero who ever lived,
and the Hollow, a creeping erasure, is unmaking the world one name at a time. Summon the echoes of lost heroes
(**N, R, SR, SSR, UR**), fight beside them, and build up the Archive Hall that holds them.

This repository is a **playable vertical slice**: a prologue, an upgradeable hub, two dungeons (two floors each),
two bosses, 13 characters and four banners (an estimated one to two hours of play).

> **Status: not yet run inside RPG Maker MV.** I could not launch the MV editor/runtime while building this, so the
> game has been verified by the tools in `tools/` and `tests/` (see *What is verified*), not by playing it in the
> engine. Expect to find small things to fix on first launch (see *Known limits*). The windows of the summon screen
> in particular have never been rendered by a real MV engine.

## Quick start

1. In **RPG Maker MV**, create a **new blank project** (File > New Project).
2. Install the game into it. With Node.js 16+ installed:
   ```
   node tools/install.js "C:\path\to\YourBlankProject"
   ```
   This copies `data/`, the generated art, and the plugins, and **merges** the game's settings into your project's own
   `System.json` (your terms, sounds and engine settings are kept; other plugins you use are kept too).
   *No Node?* Copy `data/`, `img/` and `js/` from this repo over your blank project instead (this replaces your
   `System.json` with the one in this repo).
3. Open the project in MV and press **Test Play** (Ctrl+R). The game starts in *The Waking Room*.

Characters (`Actor1`..`Actor3`), faces and the side-view battlers use MV's stock resource pack (RTP), so a normal MV
install already has them. Everything else (tileset, monsters, battlebacks, title screen) is generated by this repo.

## The slice

**Story.** The Great Archive of Lantern Reach is under attack by the Hollow. Quill, a sarcastic living book, wakes
Iri and teaches the Archive's one weapon: *echoes*, the recorded lives of heroes, which answer a summons. Down in the
Whispering Stacks the Curator has been consumed; in the Inkwell Depths something older waits behind the Warden. The
slice ends on a hook: the Hollow is not an invader, and it is hunting the First Archivist.

**Loop.** Explore dungeons, earn Echo Shards, summon echoes, level and limit-break them, spend gold and Ink Pages on
the Hall, take bounties, repeat. Duplicates are never wasted.

| System | What it does |
|---|---|
| **Summoning** | 4 banners (Beginner, Echo Summon, *Aurelian's Dawn*, *Hollow's Whisper*), 5 rarities, soft and hard pity, 50/50 rate-up with guarantee, guaranteed SR+ in a 10-pull. 100 shards per pull. |
| **Limit break** | A duplicate echo adds +6% stats (max 5). Limit break 3 teaches the echo's Burst skill. Further duplicates refund gold. |
| **Archive Hall** | Upgradeable Shrine (lower pity), Scribe's Desk (bounties and a shard dividend), Binder's Forge (better gear). Rest wing, save crystal, Echo Stand. |
| **Echo memories** | Every echo has two story scenes (the second unlocks at limit break 3) at the Echo Stand. Recruited echoes wander the Hall. |
| **Battle** | Side-view party battle with a 6-element wheel, arts (MP), Bursts (TP), buffs/debuffs and status effects, weakness-driven bosses. |
| **Dungeons** | Random encounters, treasure, levers and gates, lore fragments (eight, with milestone rewards), candles that heal. |

Details: [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md), [`docs/roster.md`](docs/roster.md) (every hero, skill and enemy),
[`docs/balance-report.txt`](docs/balance-report.txt), map previews in [`docs/maps/`](docs/maps).

## Working on the game

The `data/`, `img/` and some `js/plugins` files are **generated**; the source of truth is in `tools/src`
(heroes, skills, enemies, story, maps) and `tools/art`. Edit those and rebuild:

```
npm run build       # regenerate everything
npm run validate    # cross-references, event structure, map walkability, plugin syntax
npm test            # engine tests + scripted playthrough + validator
npm run balance     # battle simulator (win rates for sample parties at each stage)
npm run preview     # render every map to docs/maps/*.png
```

You can also open the generated project in the MV editor and keep editing it there; just don't run `npm run build`
afterwards without committing, because it regenerates the files.

## What is verified

- `tools/validate.js`: every id referenced by actors, classes, skills, items, enemies, troops, banners, events and
  common events exists; event command lists are well-formed (indents, block pairs, text boxes); every map's data has
  the right size and valid tile ids; every event can be reached from the points the player can arrive at; the lever
  doors really gate the stairs; plugin files parse.
- `tests/gacha.test.js`: pull rates, pity, guarantees, rate-up and rewards of the engine.
- `tests/playthrough.test.js`: plays the whole slice (prologue, first summon, hall facilities, limit breaks, both
  dungeons, both bosses, losing and retreating, the economy afterwards) using the **real plugin code and the real
  generated event data** inside a small re-implementation of MV's interpreter, 31 checks. It already caught a real
  bug (MV keeps the space after the colon in note tags, so `<Rarity: SSR>` is read as `" SSR"`).
- `tools/balance.js`: simulates battles with MV's damage rules (see the report for win rates by party and level).

## Known limits

- **Never run in a real MV engine.** The summon scene's windows, battle animations and audio are unverified.
- **Audio** uses stock RTP file names (`Theme1`, `Dungeon1`, `Battle1`, ...). If one is missing in your install,
  change it in `tools/src/ids.js` (`AUDIO`) and rebuild.
- **Battle animations** are looked up by name at runtime (`<Anim: Fire 1|Fire 2>` in notes), so they adapt to your
  project's animation list. Skills whose animation is not found simply play without one.
- **Hero sprites** are stock RTP characters picked by index, so a sprite may not match its description (swap it in
  the Actors tab).
- Icon indexes (items, skills, equipment) are approximate guesses at the stock IconSet.
- The art is deliberately simple (procedurally drawn). Replace it with your own whenever you like.
- This is one chapter: the gacha, hall and battle systems are complete; there is an estimated one to two hours of content.
